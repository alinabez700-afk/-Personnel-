# Проєкт: «Персонал+» (HRM System)

Система управління персоналом для автоматизації HR-процесів підприємства.

## Структура репозиторію
* `backlog.md` — Беклог продукту (User Stories).
* `processes.md` — Опис бізнес-процесів (BPMN).
